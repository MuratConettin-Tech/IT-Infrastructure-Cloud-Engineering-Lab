# Hyper-V Lab

## Objective

Install Hyper-V and create the Windows Server virtual machine

## Enviroment

Host OS:
Windows 10 Pro 22H2

CPU:
Itel Core i7-6600u

RAM:
16 GB

Guest OS:
Windows Server 2025

## Steps

- Enabled Hyper-V
- Created External Switch
- Created VM
- Installed Windows Server
