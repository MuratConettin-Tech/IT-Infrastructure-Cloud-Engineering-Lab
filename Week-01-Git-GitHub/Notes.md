# Week 01 - Git and Github

## What I Learned

- Git ia a version control system.
- Github is a cloud platform for hosting Git Repositories.
- A Repository stores project files and version history.
- A commit saves a snapshot of changes.

## Commands

- git init
- git status
- git add
- git commit
- git clone
- git push
- git pull

##Git Workflow

1. Check changes with 'git status'.
2. Add changes with 'git add'.
3. Save changes with 'git commit'.
4. Upload changes with 'git push'.
